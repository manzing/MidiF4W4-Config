Midi programing app for F4W4 device

## Requirements
Windows 10-11 x86/x64

## How to use software

Note: Software is in simulation mode at start, you can see midi messages in console and manage profiles in this mode.
You have to disable simulation mode (checkbox) to effectively set change on a control.

- Run MIDI_FF04_Configurator.exe
- Load a profile or choose CC on one or more controls
- Click the "set" button on the control you want, or "Apply ALL" if you want to set all controllers with visible settings
- Click "Save to flash" is you want your settings to be persistant after replugging the device

You can choose light or dark theme mode if you want.
